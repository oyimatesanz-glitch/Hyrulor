# Fuentes tipográficas

Esta carpeta queda preparada para fuentes locales con licencia compatible. No se han incluido archivos de fuentes en este paquete.

La primera versión usa las fuentes que resuelva el sistema a través del stack nativo de COSMIC. Para cumplir estrictamente el requisito de fuentes bundleadas, incorpore aquí los archivos licenciados de Instrument Serif o Cormorant Garamond, Inter o Geist y JetBrains Mono, y añada su registro/carga al arranque de la applet según la API de fuentes de la versión de libcosmic instalada.

No se descargan fuentes durante la ejecución.
